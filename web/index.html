RELIABILITY & SAFETY

What protects each job

⌑
Chunked transfer

Upload diterima per 64 KB dan ditulis ke file sementara sebelum job dibuat.

⟲
At-most-once retry

UUID tetap dipakai selama retry; request duplikat mengembalikan job yang sama.

⛨
Thread-safe registry

Lock melindungi status dan dedupe map; Queue membagi tugas ke worker.

◷
Timeout + backoff

DEADLINE_EXCEEDED / UNAVAILABLE memicu jeda eksponensial 0.5s dan 1s, dengan maksimum 3 attempt.

↯
Graceful shutdown

Server berhenti menerima RPC sebelum worker menerima sinyal shutdown.
